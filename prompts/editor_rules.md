# 编辑规则

主编在审核中提出的、以后每期都要遵守的规则写在这里。
系统从批注里提炼出的新规则会先放进“待确认”，主编确认后移到“已生效”。

## 已生效
- 不需要向店方申请图片授权，直接使用文章或店铺官网的图片
- 卡片和正文都不出现来源脚注
- 大标题不写“内城”
- 介绍餐厅、咖啡店时，每篇只推荐一家店，不做合集
- 单店帖子以实景照片为主，至少6张照片，文字卡片尽量少
- 中文和英文、数字之间不加空格（写“Ho Jiak的平价版”，不写“Ho Jiak 的平价版”）
- 写得有活人感，只写确认过的事实，绝不编造口味、评价和数字
- 第一张图（封面）左上角放“新店｜街区”深色小标签，下方放大标题，不写副标题等其他小字；挑最有冲击力的美食照片，高清照片用 cover_full 铺满，分辨率低的用 cover_hero
- 卡片上不放账号名
- 图片比例统一用3:4（1080×1440）
- 单店帖子不做结尾卡（closing、closing_photo），也不做“说实话/真实评价”卡
- 正文不写“说实话”“评价还很少”“网上评价”之类的评价段落
- 正文结尾不加向读者提问的句子（例如“你去过吗？欢迎在评论区说说”），卡片上也不放问题
- 图片页尽量不放字，最多一个短标签；信息集中放在店铺信息页
- 封面标题排版要有变化（整版、主图、电影截图、唱片封套等轮换），但保持简洁
- 开业超过60天的店，标签不写“新店”，改写类型，例如“咖啡｜Balmain”
